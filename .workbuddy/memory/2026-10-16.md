# 2026-10-16

## sol 默认配置改造：控制面默认开启 + `auth.token` 明文令牌

用户要求把安装脚本生成的默认 `sol.yaml` 改成 `server.http.enabled: true` / `listen: 127.0.0.1:8080` /
`auth: { type: bearer, token: <随机生成> }`，并让 auth 支持三种令牌来源（`token` / `token_env` /
`token_file`）。动手前问了 4 个问题，用户全选推荐项：安装脚本生成随机 token、三来源互斥、
注释与 README 一起改、sol.yaml 收到 0600。

- `internal/config/schema.go`：`authConfig` 新增 `token` 字段。
- `internal/config/load.go`：`resolveSecret` 多了一个首参（明文值），三种来源**互斥**（多写报
  `ErrSecret`，错误里列出已配置的来源）；5 个调用点全部改成 `resolveSecret("", …)` 形式。
- `schema/sol.schema.json`：auth 增加 `token`（`TestSchemaMirrorsTheConfigStructs` 卡一致性）。
- `scripts/install.sh`：新增 `new_control_token()`（`openssl rand -hex 32`，退回 `od /dev/urandom`），
  heredoc 改成**不带引号**（要展开 `${CONTROL_TOKEN}`），生成的 `sol.yaml` 权限 0644 → **0600**。
- `scripts/install.ps1`：同内容行数组 + `New-ControlToken`；安装目录里那份用 `icacls`
  （SID `S-1-5-18` / `S-1-5-32-544`）去掉继承、只留 SYSTEM 与 Administrators。
- `example/sol-example.yaml`（占位令牌 + 三种来源注释）、中英 README（"默认关闭"→默认开启、Control
  plane 段的令牌来源段）、`CHANGELOG.md`（Breaking / Added / Security 三处）、
  `docs/routing-design.md` 字段表、`docs/install-pitfalls.md` 第 10 条。
- 验证：`go test -tags mock -race -cover ./...` 全绿；install.sh 与 install.ps1 两份模板逐行比对一致
  （token 除外）；用真的生成配置起 `sol listen --dry-run`，日志出现
  `http control plane listening scheme=http listen=127.0.0.1:8080 auth=bearer`。
- 刻意没动：`dist/`（上次发布的产物，重跑 release.sh 才会更新）、`scripts/sol.yaml`（已存在的配置
  从不覆盖，所以本机这份仍是旧的 `enabled: false`）。
